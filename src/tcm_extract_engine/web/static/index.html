如何使用工作台

1. 导入并处理文档

选择通用或中药专业抽取，可自动处理，也可逐步确认章节方案。

2. 对照原文与图片

打开一条记录，查看结构化内容、页码、原文及关联图片。待复核标记表示还需要人工确认。

3. 核验并导出

核验后查看问题和纠错建议，再下载知识、证据与质量报告。导出文件不会自动代表人工审核通过。

任务失败怎么办？

使用“重试当前步骤”，系统会复用兼容的成功缓存。只有需要变更方案或提示词时，才重新处理相应步骤。
