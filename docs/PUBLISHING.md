# 发布与隐私说明

## 上传范围

源码、领域包、提示词模板、测试、通用导出与维护脚本、README、依赖配置与 `uv.lock`。

工作区产物已停止跟踪；本地文件保留。所有 PDF、评估数据、个人简历、日志、缓存、AI 工具配置和凭据目录默认忽略。三个依赖本地私有书籍或个人机器路径的实验脚本也仅保留在本地。

## 发布前检查

```bash
git status --short
git diff --cached --stat
git diff --cached --name-only
git ls-files workspace evaluation resume .aws .codex .agents .qoder
git check-ignore .env workspace/privacy-check.json evaluation/privacy-check.json
```

第四条命令应无输出。检查新增文件时只暂存已审阅的路径，避免习惯性执行 `git add -A`。

隐私扫描需同时检查当前文件、暂存区和历史提交。可结合凭据格式扫描、真实本地密钥的精确匹配、个人路径与内网地址检查；扫描结果只报告文件名和行号，不展示密钥原值。自动扫描无法证明不存在全部隐私或受版权保护内容。

## 历史边界

已有初始提交包含样例工作区工件，其中有历史机器路径。当前版本停止跟踪这些文件，不会从历史中抹除它们。本次整理未重写提交，也不使用强制推送。

若需要清理历史，应先备份、确认影响范围，与协作者协调后再单独执行历史清理。若以后发现真实密钥进入历史，首先撤销或轮换密钥，然后再清理仓库；删除最新版本中的文件不能撤销已经泄露的凭据。

## 模型服务与数据

使用远程模型会发送文本片段、图片及提示词。不要在未获授权时处理患者信息、内部文档或受限制的书籍。发布导出结果前检查原文、图像、页码、文件名和审核备注；不要将自动抽取或核验结果直接用于临床决策。

Web 服务建议绑定回环地址 `127.0.0.1`。对外部署需另行配置认证、授权、HTTPS、上传限制和日志管理。
